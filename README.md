## Projenin Tanıtımı

Bu proje, ASP.NET Core MVC ile geliştirilen bir **veteriner kliniği randevu ve hasta takip sistemidir**.
Sistem; kliniğin sunduğu hizmetleri, veteriner hekimleri ve uzmanlık alanlarını, evcil hayvanların
muayene ve aşı geçmişini ve hayvan sahiplerinin randevularını yönetir.

Uygulama ayrıca kendi işlevlerini bir yapay zekâ asistanının çağırabileceği araçlar olarak sunan bir
**MCP (Model Context Protocol) sunucusu** içerir.

### Kullanılan Teknolojiler

- ASP.NET Core MVC (.NET 10 LTS), C#
- Entity Framework Core (Code First, Migration), LINQ
- SQLite
- ASP.NET Core Identity (rol bazlı yetkilendirme: Admin, Veteriner, Üye)
- ModelContextProtocol.AspNetCore (MCP C# SDK)
- Bootstrap 5, HTML5, CSS3, JavaScript, jQuery
